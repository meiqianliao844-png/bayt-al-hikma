# 神秘顾客01字幕导入

数据来源为用户在对话中提供的23行中阿字幕与标题，资料日期2026-10-03，入库日期2026-10-31。原文仅统一空格；没有音频可核对。1.0x和播放器时间不作为台词。全部原字幕保留在源JSON和转换报告中。

源文件 `data/imports/spongebob-mystery-01.curated.json` 将原字幕与学习整理字段分开。原文声称12个重点，但未附重点清单；本次整理选出12项重点，并补充12项场景词，共24张卡、11个动词档案和102道选择题。源日期用于卡片日期，入库日期在来源说明中另行记录。

所有动词覆盖：تَذَكَّرَ、وَجَدَ（含 يُوجَدُ 存在用法）、ذَهَبَ、لَا يَزَالُ、لَيْسَ、حَاوَلَ、عَادَ、تَعَالَ、اِسْتَمْتَعَ、أَمْسَكَ、هَرَبَ。不为لَيْسَ虚构现在式；不把تَعَالَى“超越”等义机械填作تَعَالَ“过来”的过去式；不将زَوَالٌ“消失”混作لا يزال“仍然”的动名词。

例句均逐字复用用户字幕和中文，标注“原字幕／用户提供／未核音”。教学整理的词典式搭配单独标记“台词搭配（整理形式）”。不把原“章鱼哥单簧管”专题替换为本专题，使用独立稳定ID。顾客成群一句可能为反讽，中文按原字幕保留并提示语气。

字词辨析参考：开罗阿拉伯语科学院 مسك 词条 https://www.arabicacademy.gov.eg/ar/search_engine/roots/%D9%85%D8%B3%D9%83 （区分أمسك بـ与أمسك عن）；半岛阿语教学 https://learning.aljazeera.net/tr/node/19582 （كان及姐妹动词的主语、谓语格位）。这些不是片段字幕的外部出处。

运行 `npm run convert:mystery` 可重新生成经现有Schema验证的知识包及报告。完整下载副本由 `npm run sync:assets` 同步到public/packs。安装使用已有追加与去重逻辑，不改State版本、存储键或旧数据。单元测试覆盖原字幕一致性、动词覆盖、去重、旧学习记录、批注和日记保留；端到端测试覆盖专题筛选、词形、原句、选择练习和背词保存。
