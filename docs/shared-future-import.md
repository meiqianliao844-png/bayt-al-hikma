# 第02讲人类命运共同体语料导入

导入用户提供的三栏 Word 表：85 条中阿对应表达，按六个学习主题生成85张独立词卡和170道双向选择题。自动加入背词库，首次评分后按已有 wordProgress 机制生成复习计划。原有数据、收藏、批注、题目进度和词卡进度不变。

源文件个人信息未复制进公开仓库。正文表格抽取为 `data/imports/shared-future.corpus.json`，保留原始中阿文字与源文件 SHA256。标题外的作者元数据不提取。可用 `scripts/extract-corpus-docx.py INPUT.docx OUTPUT.json` 在本地重现抽取；遇到非三列表头、空值或重复编号即拒绝。

`shared-future.vocalized.txt` 按行补充学习标符，独立词组词尾不代表整句中恒定的格位。`scripts/convert-corpus.mjs` 对照原表逐条核验去标符后的字母；除第73条明确校订外，不允许词汇变化。无完整文章，不把这些表达标为文章引文，不虚构例句或动词变位。

第73条原文 استناد الأقوياء على الضعفاء 与“恃强凌弱”不对应，改用 اسْتِئْسَادُ الْأَقْوِيَاءِ عَلَى الضُّعَفَاءِ。卡片来源说明、辨析与转换报告保留原文及原因。参考巴勒斯坦通讯社刊载中国驻巴大使讲话：https://www.wafa.ps/pages/details/58263 。本次导入不声称其他全部条目都已与官方原文逐条核对。

转换后通过现有 JSON Schema 验证，不改变 schemaVersion、存储键和 State 版本。ID 以专题和原表编号构成；重复导入可去重。重新生成：`npm run convert:corpus`，下载副本随 `npm run sync:assets` 同步。

复习数量说明：今日到期只计到期和逾期词卡，首次学习次日到期。首页、背词及复习页补充显示已背词卡、今日到期、未来已安排和下次复习日期，避免把今日为0误认为记录未保存。
