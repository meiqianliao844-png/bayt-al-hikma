# 神秘顾客续篇与单复数补充

本批来源为用户继续提供的21条字幕，未提供音频和发布日期，以2026-10-31记录入库日期。原文保留；M09、M10、M18、M20中文为补译，例句注明补译，杂志名称按字面暂译。播放器时间不作为台词。

本批48项知识引用中，30项新增，18项明确映射已有知识ID，只补充新台词、搭配和用法，不重复创建“返回、抓住、尝试、说、想要、钱币、神秘”等卡片。旧库此前已有的记录不删除或重排。新包的通用释义、词根、词形练习只为新卡生成；复用卡仅补充续篇的上下文题。合计136道选择题。

新增的补充安装路径采用“已有文本优先”的递归补缺，数组按阿语、来源名、人称或单复数对去重。个人编辑、收藏、批注、进度、历史及小记不覆盖；用户删除的旧卡不会因续篇复用而复活，引用已删除卡片的新增题跳过。与个人自建卡阿语和中文释义均严格一致时复用该个人ID，相关新题自动改指该ID；不对不同义项做模糊合并。

M03的“هل أعرني”疑似不规范，保留原字幕并另列“هل تعيرني...”的学习规范改写，不用原组合训练正确句型。M02数量表达另列规范改写。出借方向和词根参照开罗阿拉伯语科学院：https://www.arabicacademy.gov.eg/ar/search_engine/roots/%D8%B9%D9%88%D8%B1 。水母词形参照：https://www.arabicacademy.gov.eg/ar/search_engine/roots/%D9%82%D9%86%D8%AF%D9%84 。这些是词汇参考，不是音视频字幕出处。

JSON Schema保持v1并增加可选 `vocabulary.noun.numberPairs`：每项必须有 `singular` 和 `plural`，可有 `chinese`、`note`。普通单词可继续使用 `noun.singular` 与 `noun.plurals`；复合词组内的复数、不同近义词各自的复数，以 `numberPairs` 分开描述。不能为整个“内阁”编造单数“某位部长的委员会”。不强制旧包改格式，备份向后兼容。

`src/noun-numbers.mjs` 为人工整理的单复数对应表，按已知词形识别主词、搭配和例句中的复数并显示单数。只匹配明确词形及定冠词、连词和领属后缀，不根据词根机械造词；借词、集合用法、品牌名保持说明。已有人工作出的词形不覆盖。卡片释义、词形页与背词翻面显示对照；动词卡片显示“例句名词”，不把动词当名词做单复数变化。

新专题的背词入口带入专题查询，使复用卡片优先显示本次台词。复数对应随学习数据备份，壁纸存储不改变。转换命令为 `npm run convert:mystery02`，下载副本随 `npm run sync:assets` 同步。原存储键及State版本不变。
