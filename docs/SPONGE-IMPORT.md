# 海绵宝宝01专题

本批上传原 JSON 保存在 `data/imports/spongebob-01.portable.json`，含 54 组动词搭配、54 条词汇与 4 条字幕核对备注。没有将两份 CSV 再次导入，以免重复。

## 格式适配

虽然与新闻包都声明 `wisdom-house-learning-pack-portable-v1`，但本包词汇用 `type:term / meaning_zh`，并在顶层提供 source；动词没有逐条 usage_note/source。适配器显式识别动画字幕变体，验证后补接顶层来源、规范化词汇字段，再生成原生 `schemaVersion:1` 数据。不能仅因 schema 标识相同就直接按新闻字段读取。

```bash
npm run convert:sponge
```

生成 108 张卡片、283 道题（54 道搭配填空、13 道限定介词填空、108 道释义选择、中译阿与阿译中各 54 道）。源包的词形、搭配、例句和中文均保留，不新造被动分词或其他未给定形式。

来源/语体标记为动画配音学习资料，不冒充已核实的地区方言。例句是原包编写的教学句，不作为已经核音的逐字字幕。

## 需要特别说明的条目

- `sponge-v002` 动名词栏混有中文解释，且说明“存在”与“找到”的语义区别。保留整段说明到词形备注，动名词字段留待核对，不把注释当作一个阿语词形。
- `sponge-v017`、`sponge-v032` 主要学习固定表达，不将整句意思直接等同于源动词的一般词义。
- `sponge-v038` 的词头是 `مَلَكَ`，而搭配和例句用 `اِمْتَلَكَ`。保留原记录，明确区别，并链接 `sponge-v041` 的独立词形档案。
- 4 条 review_notes 原样保存于转换报告，并在专题入口的“字幕核对备注”中显示；不是经过听音确认的标准答案，也不自动拿来生成纠错题。
- 动画选择题避免以含有相同核心中文片段的释义作干扰项，例如不同时给出两种“拥有”释义来制造假错误。中阿翻译仍使用自评。

## 合并到现有学习库

多专题注册表保留新闻专题，再追加动画专题。沿用现有 installedPacks 标记逐包安装，默认不覆盖同 ID 用户内容、不写入旧进度。加载时仅做内存合并，正常保存时才持久化。已经安装的条目不会在用户主动删除后被强行恢复。

原校服新闻转换结果、源 seed、JSON Schema、存储键、State.version 及 GitHub Pages/Validate 工作流保持不变。安装过新闻的旧浏览器会追加 108 张动画卡及 283 道题；新浏览器合计自带 221 张卡、580 道题（含原始 7 张/20 道）。
