# 第一版验证记录

验证日期：2026-10-25。环境：Node.js 24，Linux Chromium。代码未依赖 API 密钥或外部数据库。

- `npm ci --cache /workspace/.npm-cache`：基于锁文件重复安装依赖。
- `npm run build`：TypeScript 严格检查、Vite 生产构建。
- `npm test`：8 项核心测试。覆盖首批知识包和八种题型、重复 ID/悬空引用/错误选项/无效日期、默认保留及显式覆盖、1/3/7/14/30 天调度、错误重置、完整备份往返与损坏拒绝、删除关联清理、阿语搜索标符归一化。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`：桌面 1440×1000 和手机 390×844，各 6 项，共 12 项浏览器测试。覆盖知识增删改、收藏、刷新持久化与 RTL；客观批改、错题记录与翻译自评；导入校验、预览、去重、更新、备份导出与恢复；无阿语音色的真实提示、无横向溢出；录音、音频播放及退出清理；存储空间不足时保留编辑器并报错。

另以生产预览运行 `dist/`，验证知识搜索、RTL 原文、导入页面和示例包下载，浏览器没有运行错误。开发服务器在指定端口的文档及示例包请求也已通过。

录音测试使用 Chromium 提供的模拟麦克风，验证 MediaRecorder 与音频回放链路，不代表真实麦克风或录音质量验证。测试环境没有阿语系统音色，已验证“不支持时提示”的分支；真人语音质量需在有阿语音色的设备上体验。没有自动发音评分。

端到端截图由测试生成到 `test-results/`，不提交生成物。当前没有真实用户账号、多设备同步、远端数据库或付费语音服务。

发布流程与公网域名尚需维护者按 README 执行；本地构建和测试通过不等于已在 GitHub Pages 部署。
