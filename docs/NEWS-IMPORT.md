# 阿塞拜疆校服新闻知识包导入

## 原文件与现有格式的区别

本次使用上传的 JSON 原文件，完整保存在 `data/imports/azerbaijan-school-uniform.portable.json`。两份 CSV 没有再次导入，避免与 JSON 中相同条目重复。

原文件声明 `schema: wisdom-house-learning-pack-portable-v1`、字符串 `version: "1.0"`，含 `verbs`（51）和 `terms`（55）；网站原生格式是数字 `schemaVersion: 1`、`id/title/knowledge/questions`。原文件不满足原生 Schema，不能直接当作 Pack 类型使用。

适配器 `src/portable-news.mjs` 先验证原格式与每条必需内容、日期、类型及重复 ID，再转换；`scripts/convert-news.mjs` 使用项目当前的 `src/knowledge-pack.schema.json` 和 Ajv 验证生成结果，同时检查题目关联及选项。网站导入入口也调用同一适配器，因此仍可选择原始上传文件，预览转换结果后再确认。

## 可复现的转换

```bash
npm run convert:news
# 也可显式传入路径：
npm run convert:news -- --input source.json --output output.json --report report.json
```

默认生成：

- `src/data/azerbaijan-school-uniform.json`：106 张知识卡、277 道题。
- `src/data/azerbaijan-school-uniform.report.json`：转换数量、来源说明、特殊词形的处理记录。

开发启动和构建时重新转换并校验，再同步到 `public/packs/`，网页“知识包与备份”提供下载。没有修改原 Schema 的既有必填结构，没有改动原 `src/seed.json`，没有更改 GitHub Pages 部署工作流。

| 原字段                   | 卡片字段 / 处理                                                           |
| ------------------------ | ------------------------------------------------------------------------- |
| verbs[].lemma            | arabic；通常也是 verb.past，情态现在式除外                                |
| imperfect / masdar       | verb.present / verb.masdar；占位符省略，说明资料暂缺                      |

ID 使用日期和包标题的稳定命名空间，再加原条目 ID；动词与术语分别命名，避免通用 `v001/t001` 与其他知识包冲突。相同原文件重复转换得到完全一致的 ID 与内容。请保持原包标题和学习日期稳定；若要改标题又保留 ID，请使用已转换的原生包。

所有词头、搭配、例句和译文均来自原文件，不依据词根批量推导词形。保留原标符；不声称已经完成逐条词典核验或新闻事实核查。

- v031 的动名词占位符留空，显示尚未补充。
- v048 `يَنْبَغِي` 为给定的情态现在式，放到 present，不误填过去式，也不补造动名词。
- v042 保留 `وُجِدَ / يُوجَدُ` 的被动形式与存在句用法，不误改为主动词。
- v036 原备注“双宾语框架”保留在来源说明，同时指出实际搭配是宾语与 `مِنْ` 介词补语，避免把两个成分都当作直接宾语。
- v041 所给搭配和例句用义不同，卡片明确提示。

## 练习生成

每组动词生成四道基础题：搭配第一处词形填空、搭配释义选择、中译阿、阿译中，共 204 道；另从没有斜线备选、介词为独立词的框架提取 18 道介词填空。55 个术语各生成一道释义选择题，总计 277 道。

选择题干扰项取自原包其他条目的中文释义，去除重复和明显文字重叠；术语优先使用其他新闻主题的释义。不会生成不存在的阿语词形来当干扰项。所有题目带稳定 ID、knowledgeId、答案与解析。

限定词形/介词填空采用 exact 模式，忽略可选标符和多余空格。多框架备选和附着介词不强行拆词，不把可用的另一介词误判为错误。中阿互译统一用 self 模式，提供参考、解析和评分要点，不机械匹配完整译文。

## 安全加入已有学习库

`installBundledNews` 在初次打开新版时追加内容，使用现有 `mergePack(..., false)` 保留相同 ID 的用户编辑。原卡片、题目、收藏、答题历史和复习时间不改变。新卡片复用现有收藏、正常/慢速朗读、知识练习页、错题和间隔复习功能；术语也有练习，能够进入复习计划。

备份结构只增加可选 `installedPacks` 标记，仍为 version:1，仍使用 `hikma-v1`。初始加载只在内存合并，不做存储写入；后续正常保存、收藏或答题时一起保存，因此存储空间不足不会触发旧数据覆盖。标记保存后不再重复安装，也尊重用户明确删除某条内容的操作。没有任何清空浏览器或重建用户库的操作。

恢复旧备份时同样先校验，再补入本批专题并在恢复预览中显示数量。默认手动导入保持既有 ID，不覆盖用户内容；勾选更新才按原有补充规则更新。

在“每日知识库”点击“查看新闻专题”，可按新闻主题分组查看这 106 条；“专题练习”只包含该专题当前仍存在的题目。
